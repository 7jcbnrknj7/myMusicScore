# Repository documentation rules

- Maintain three complete, equivalent root introductions: `README.md` (Simplified Chinese, default), `README.ja.md` (Japanese), and `README.en.md` (English).
- Start each README with links to all three languages: [简体中文](README.md) | [日本語](README.ja.md) | [English](README.en.md).
- Update all three versions together whenever README content changes. Translate the full introduction, setup, usage, limitations, validation status, attribution, and licensing; do not replace a translation with a short summary.
- Keep project names, filenames, paths, commands, API identifiers, version numbers, and factual claims consistent. Localize prose and link labels; preserve working relative links and media.
- Do not claim planned features are delivered, turn historical checks into guarantees, or grant rights not granted by the source material.
- This convention applies to future README creation and maintenance in this repository. Other documentation need not be translated unless requested.
